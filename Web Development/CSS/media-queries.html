Why This Matters

Even with fluid units and auto-wrapping grids, interfaces still need targeted adjustments at key screen widths. For instance, a desktop site might display a horizontal list of links, while a mobile phone benefits from a tucked-away slide-out menu.

Media queries also allow websites to adapt to user operating system settings, such as prefers-color-scheme for automatic dark mode and prefers-reduced-motion for users with vestibular disorders.

Concept

Media queries consist of a media type (screen, print) and one or more conditional feature expressions:

  • Mobile-First Pattern: Write base styles outside media queries for mobile devices first, then use min-width conditions to progressively enhance the layout as more screen real estate becomes available.
  • Modern Range Syntax: Replaces older, clunkier rules like (min-width: 768px) with intuitive mathematical comparisons: (width >= 768px).
  • User Preference Media Features: Detect hardware capabilities and system settings:
    • prefers-color-scheme: dark | light
    • prefers-reduced-motion: reduce
    • hover: hover (differentiates touchscreens from mouse pointers)

Syntax

/* 1. Base styles (Mobile First) */
.content-layout {
    display: flex;
    flex-direction: column;
    gap: 1.5rem;
}

/* 2. Modern Range Syntax for Tablet / Desktop */
@media (width >= 768px) {
    .content-layout {
        flex-direction: row;
    }
}

/* 3. Handling Dark Mode Preferences */
@media (prefers-color-scheme: dark) {
    :root {
        --bg-color: #0f172a;
        --text-color: #f8fafc;
    }
}

/* 4. Respecting Motion Preferences */
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
        scroll-behavior: auto !important;
    }
}
