Concept

Media Queries are CSS conditional directives that apply specific style rules only when the device matches specified criteria, such as viewport width, display orientation, or system accessibility settings.

CSS 
/* Modern Range Syntax */
@media (width >= 768px) {
  .grid-layout {
    grid-template-columns: 1fr 1fr;
  }
}

Why This Matters

Fluid units can handle gradual resizing, but major layout shifts—like hiding a sidebar, switching a navigation bar to a slide-out drawer, or updating theme colors for dark mode—require media query breakpoints to control presentation across device types.

Types & Features

Key components that make up a media query:

  • Media Types: all, screen (standard monitors/phones), and print (print layout overrides).
  • Viewport Features: width, height, and orientation (portrait vs. landscape).
  • Hardware Features: hover: hover and pointer: fine (differentiates touchscreens from mouse inputs).

Modern Range Syntax

Modern CSS supports range comparison operators (>=, <=) in place of older min-width/max-width declarations:

CSS 
/* Target viewport widths between 600px and 1000px */
@media (600px <= width <= 1000px) {
  .sidebar {
    display: none;
  }
}

/* Equivalent legacy syntax */
@media (min-width: 600px) and (max-width: 1000px) {
  .sidebar {
    display: none;
  }
}

User Preference Queries

Respect system settings using accessibility and theme media features:

CSS 
/* Dark Mode Theme */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-page: #0b1329;
    --text-body: #f1f5f9;
  }
}

/* Reduced Motion Safety */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

Common Mistakes

  • Tying breakpoints to specific device dimensions (e.g., exactly 375px for iPhone) instead of adjusting based on when the content itself naturally breaks.
  • Overwriting mobile styles with max-width queries instead of using mobile-first min-width rules.
  • Forgetting to test print stylesheets using @media print, which can leave background graphics unoptimized for printing.

Interview Questions

Q: What is the purpose of the prefers-reduced-motion media feature?

It checks whether the user has enabled a system setting to minimize non-essential motion, helping prevent vestibular motion sickness caused by large animations.

Quick Revision

Write base styles for mobile first, then layer on enhancements with @media (width >= 768px). Use modern range syntax for cleaner conditionals, and support dark mode and reduced motion using user preference features.

Practice Problems

  1. Create an automatic dark mode color theme that responds to system settings with prefers-color-scheme.
  2. Build a multi-step card layout that shifts from 1 column on mobile, to 2 columns on tablets, to 4 columns on widescreen desktops.
