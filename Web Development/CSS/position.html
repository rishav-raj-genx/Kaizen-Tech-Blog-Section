Concept

The position property determines how an element is placed within the document flow and whether coordinate offsets (top, right, bottom, left) apply to it.

CSS 
.modal {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

Why This Matters

Elements sit in normal document flow by default, ordered as they appear in the HTML. UI components like notification badges, sticky headers, tooltips, and modal overlays require breaking out of that flow and positioning elements relative to specific containers or the viewport.

The 5 Position Values

  • static: The default value. Elements follow normal document flow; offset properties have no effect.
  • relative: Elements stay in normal flow, but can be shifted using offsets without affecting neighboring elements. It also acts as an anchor for absolute children.
  • absolute: Removed from the document flow and positioned relative to the nearest positioned ancestor.
  • fixed: Removed from the document flow and pinned directly to the browser viewport coordinates, staying in place on scroll.
  • sticky: Behaves like relative until a scroll threshold is met, at which point it sticks like a fixed element within its parent container.

Positioning Coordinates Flow

DIAGRAM 
Normal Flow → Relative → Absolute → Fixed → Sticky

+-------------------------------------------------------------+
| Parent: position: relative;                                 |
|                                                             |
|  Normal Flow Element                                        |
|                                                             |
|  +---------------------------+                              |
|  | Child: position: absolute | <-- Positioned relative to    |
|  |        top: 0; right: 0;  |     parent boundary          |
|  +---------------------------+                              |
+-------------------------------------------------------------+

Syntax & Offsets

CSS 
.card {
  position: relative; /* Anchors the absolute badge */
  padding: 1.5rem;
}

.card-badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

.navbar {
  position: sticky;
  top: 0;
  z-index: 100;
}

z-index & Stacking Context

The z-index property controls layer ordering along the z-axis (depth). It only works on positioned elements (those with a position other than static) or direct flex/grid children.

Common Mistakes

  • Using position: absolute without setting position: relative on the parent, causing the child to position itself relative to the <body> element instead.
  • Applying position: sticky inside a parent container that has overflow: hidden set, which prevents the sticky behavior from working.
  • Using unnecessarily high z-index values (like z-index: 999999) instead of managing stacking contexts cleanly.

Interview Questions

Q: What triggers a new Stacking Context in CSS?

A stacking context is formed by setting position: relative/absolute with a z-index other than auto, setting opacity to less than 1, or using properties like transform, filter, or contain.

Quick Revision

Anchor absolute children by adding position: relative to their parent container. Pin elements to the viewport using fixed, and create sticky headers with position: sticky paired with top: 0.
