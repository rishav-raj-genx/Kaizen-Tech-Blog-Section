Why This Matters

Every element in HTML lives within the "normal document flow" by default, sitting on the page based on its order in the source code. Modals, badges, sticky headers, and floating notifications require breaking out of that flow.

Without a clear grasp of containing blocks and stacking contexts, setting top: 0; left: 0 on an element can cause it to fly to the top of the entire viewport instead of its parent container.

Concept

The position property takes five core values:

  • static: The default. Remains strictly within the normal document flow. Offset properties (top, left, etc.) have no effect.
  • relative: Remains in the flow, preserving its original space, but can be shifted relative to its starting position using offsets. Critically, it acts as an anchor for absolute children.
  • absolute: Pulled entirely out of document flow. Positioned relative to its nearest ancestor with a position other than static.
  • fixed: Pulled out of the flow and pinned directly to the browser viewport coordinates. It stays fixed in place during scrolling.
  • sticky: Acts as relative until a scroll threshold is met (e.g., top: 0), at which point it pins itself like a fixed element within its parent container.

Syntax

/* Relative parent anchoring absolute badge */
.product-card {
    position: relative;
    width: 300px;
    padding: 1.5rem;
}

.discount-badge {
    position: absolute;
    top: 10px;
    right: 10px;
    background-color: #ef4444;
    color: white;
}

/* Sticky site header */
.primary-header {
    position: sticky;
    top: 0;
    z-index: 1000;
    background-color: #0f172a;
}
