Concept

The Flexible Box Module (Flexbox) is a one-dimensional layout system designed to distribute space along a single row or column while handling element alignment and dynamic sizing.

CSS 
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Why This Matters

Before Flexbox, vertical centering and variable-width columns required fragile hacks with floats, tables, and clearing elements. Flexbox makes child elements expand to fill unused space or shrink to avoid overflowing, keeping navigation headers and cards aligned as screens resize.

Flexbox Terminology

  • Flex Container: The parent element on which display: flex is declared.
  • Flex Items: Direct children of the flex container.
  • Main Axis: The primary layout direction (defaults to horizontal with flex-direction: row).
  • Cross Axis: The perpendicular axis (defaults to vertical when layout is row-based).

Main Properties

Key properties categorized by parent container and child items:

  • justify-content: Aligns items along the Main Axis (e.g., center, space-between).
  • align-items: Aligns items across the Cross Axis (e.g., center, stretch).
  • flex-wrap: Allows items to wrap onto multiple lines (nowrap, wrap).
  • flex-grow, flex-shrink, flex-basis: Controls item scaling and starting widths.

Syntax

CSS 
.nav-bar {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 1.5rem;
}

.search-input {
  /* grow | shrink | basis */
  flex: 1 1 250px;
}

Real-World Applications

Flexbox is ideal for one-dimensional UI components:

  • Navigation bars with logos on the left and links pushed to the right.
  • Centering content modals vertically and horizontally.
  • Form input groups where a text input expands to fill space next to a fixed-width button.

Common Mistakes

  • Using justify-content when trying to align items along the cross axis (which requires align-items).
  • Forgetting that switching flex-direction to column swaps the behavior of the main and cross axes.
  • Using Flexbox to build two-dimensional layouts with complex row and column alignments (which are better suited for CSS Grid).

Interview Questions

Q: What does the shorthand flex: 1 mean?

It expands to flex-grow: 1; flex-shrink: 1; flex-basis: 0%;, allowing the flex item to grow and shrink dynamically relative to other items in the container.

Quick Revision

Set display: flex on the parent element. Use justify-content to align items along the main axis, align-items for the cross axis, and the gap property to add space between items without using margins.

Practice Problems

  1. Build a navigation bar with a logo, menu links, and an action button using justify-content: space-between.
  2. Center a modal dialog card horizontally and vertically inside a full-screen wrapper.
