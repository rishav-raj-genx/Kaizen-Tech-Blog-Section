Why This Matters

Prior to Flexbox, centering an element both vertically and horizontally required hacks involving display: table-cell, negative margins, or absolute positioning with transforms. Even a simple navigation bar with a logo on the left and menu items on the right required fragile float and clearfix rules.

Flexbox solved this by making containers dynamically stretch, shrink, and redistribute leftover space among child items as the browser viewport resizes.

Concept

Flexbox works on a parent-child relationship across two distinct axes:

  • Flex Container: The parent element on which you declare display: flex or display: inline-flex.
  • Main Axis: The primary axis along which children are ordered, defined by flex-direction (defaults to row, left-to-right).
  • Cross Axis: Perpendicular to the main axis. If the main axis is horizontal, the cross axis is vertical.
  • Justify vs. Align: justify-content controls alignment on the Main Axis; align-items controls alignment on the Cross Axis.

Visual Diagram

   Main Axis ---> (flex-direction: row)
   +-------------------------------------------------------------------+
 C |  [Item 1]               [Item 2]               [Item 3]           |

 o |  justify-content: space-between (distributes along main axis)     |
 s |  align-items: center            (aligns along cross axis)         |

   +-------------------------------------------------------------------+
   v Cross Axis (perpendicular to Main Axis)

Syntax

/* Container properties */
.navbar {
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
    gap: 1.5rem;
}

/* Child item properties */
.nav-item-expand {
    /* flex-grow | flex-shrink | flex-basis */
    flex: 1 1 200px;
}

.nav-cta {
    /* Override parent alignment locally */
    align-self: flex-end;
}
