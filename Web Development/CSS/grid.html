CSS Grid Layout

Build complex, two-dimensional responsive layouts across rows and columns simultaneously with CSS Grid.

Why This Matters

While Flexbox is designed for one-dimensional rows or columns, real-world application layouts (such as SaaS dashboards, photo galleries, and magazine feeds) require simultaneous alignment across two dimensions: columns and rows.

Without CSS Grid, building these interfaces requires nesting multiple rows of flex containers, which leads to layout drift and fragile responsive breakpoints. Grid lets you define the entire layout structure directly on the parent container.

Concept

CSS Grid introduces a dedicated set of coordinate terms:

  • Grid Lines: The numbered horizontal and vertical dividing lines defining the grid edges (indexed starting at 1).
  • Grid Tracks: The space between any two adjacent grid lines (a column or a row).
  • The fr Unit: Represents a fraction of the leftover free space in the grid container.
  • minmax() & auto-fit: Generates fully responsive galleries that adapt automatically without requiring a single media query.

Syntax

/* Dashboard layout with template areas */
.dashboard-grid {
    display: grid;
    grid-template-columns: 240px 1fr;
    grid-template-rows: 60px 1fr 40px;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
    gap: 1rem;
    height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

/* Responsive card layout without media queries */
.card-gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 1.5rem;
}
