Concept

CSS Grid is a two-dimensional layout system that lets you place child items across both rows and columns at the same time using a coordinate system defined on the parent element.

CSS 
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1.5rem;
}

Why This Matters

Flexbox works along one dimension (a row or a column). Creating full dashboard layouts, magazine article grids, or photo galleries with Flexbox requires nesting multiple rows and managing widths manually. CSS Grid lets you configure the entire page structure on a single parent element.

Grid Terminology

  • Grid Lines: The numbered horizontal and vertical lines that form the grid structure (indexed starting at 1).
  • Grid Track: The space between two adjacent grid lines (a row or a column).
  • The fr Unit: A fraction unit representing a share of the available free space in the container.
  • Grid Cell: A single unit of the grid, formed by the intersection of one row and one column.

Syntax & Template Areas

Defining layouts with named grid template areas:

CSS 
.app-layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 60px 1fr 40px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  height: 100vh;
}

header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: main; }
footer { grid-area: footer; }

Responsive Grid Without Media Queries

Combine auto-fit and minmax() to create responsive galleries that adapt automatically:

CSS 
.card-deck {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
}

Common Mistakes

  • Confusing auto-fill and auto-fit: auto-fill reserves empty tracks, while auto-fit stretches visible items to fill leftover space.
  • Relying on media queries to wrap card galleries instead of using repeat(auto-fit, minmax(...)).
  • Forgetting that grid lines are indexed starting at 1, not 0.

Interview Questions

Q: When should you use CSS Grid versus Flexbox?

Use Flexbox for one-dimensional layouts where content should dictate spacing (like navbars or buttons). Use CSS Grid for two-dimensional layouts where alignment across both rows and columns matters (like page templates or card collections).

Quick Revision

Use display: grid on the parent element. Define column sizing with grid-template-columns and fr units, use grid-template-areas for page layouts, and manage spacing between items with gap.

Practice Problems

  1. Build a responsive photo gallery where featured photos span 2 rows and 2 columns.
  2. Create an application layout using named grid template areas for the header, sidebar, main view, and footer.
