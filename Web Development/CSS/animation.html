Concept

CSS Animations let you animate changes in CSS property values over time using @keyframes, creating complex multi-step motion sequences without requiring JavaScript.

CSS 
@keyframes slideIn {
  from { transform: translateX(-100%); }
  to   { transform: translateX(0); }
}

.sidebar {
  animation: slideIn 0.3s ease-out forwards;
}

Why This Matters

Motion provides helpful visual feedback—such as skeleton loaders indicating network progress, pulse effects highlighting notifications, and slide-in notifications. Animating the right properties helps you deliver smooth 60fps animations without causing UI lag.

Keyframe Mechanics

Animations rely on two core components:

  • @keyframes: Outlines styles at designated timeline points using percentages (0% to 100%).
  • animation-duration: Total time required to complete one animation cycle.
  • animation-timing-function: Speed curve of the animation (e.g., ease, linear, cubic-bezier).
  • animation-iteration-count: How many times the animation runs (e.g., infinite or a specific number).
  • animation-fill-mode: Controls whether styles apply before the animation starts or remain after it ends (e.g., forwards).

Syntax & Properties

CSS 
@keyframes spinnerRotate {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

.spinner {
  /* name | duration | timing | count */
  animation: spinnerRotate 1s linear infinite;
  will-change: transform;
}

Performance Optimization

For smooth 60fps performance, only animate properties that bypass browser layout recalculations:

  • Performant: transform (translate, rotate, scale) and opacity.
  • Expensive: width, height, top, left, and margin (these force full layout recalculations).

Common Mistakes

  • Animating layout properties like margin-top or height, which causes choppy animations on mobile devices.
  • Forgetting to set animation-fill-mode: forwards, causing the element to snap back to its initial state when the animation completes.
  • Ignoring the prefers-reduced-motion media query for users who are sensitive to motion.

Interview Questions

Q: Why are transforms better to animate than top and left offsets?

transform animations are handled by the GPU compositor layer, meaning they don't trigger browser layout reflows or repaints.

Quick Revision

Define keyframe steps using @keyframes name { 0% {} 100% {} }. Stick to animating transform and opacity for smooth performance, and respect motion preferences using prefers-reduced-motion.
