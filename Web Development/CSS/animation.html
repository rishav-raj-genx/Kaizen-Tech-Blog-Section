Why This Matters

Animations give users immediate feedback—like a pulse on an active status badge, a skeleton placeholder while fetching data, or an alert banner sliding into view. However, poorly implemented animations cause layout thrashing and choppy frame rates.

Animating geometry properties like width, height, or top forces the browser engine to recalculate page layout on every frame. Knowing how to animate hardware-accelerated properties (transform and opacity) keeps motion running at a silky smooth 60fps.

Concept

CSS animations rely on two primary components:

  • The @keyframes Rule: Outlines the visual checkpoints across the timeline using percentages (0% to 100%) or the keywords from and to.
  • Animation Properties: Directs how the element handles keyframes:
    • animation-name: Matches the keyframe identifier.
    • animation-duration: Total time taken for one full cycle.
    • animation-timing-function: Speed curve (e.g., ease-in-out, cubic-bezier).
    • animation-iteration-count: Iteration limit (e.g., infinite, 3).
    • animation-fill-mode: How styles persist before and after execution (e.g., forwards, backwards).

Syntax

/* Keyframe definition */
@keyframes pulseGlow {
    0% {
        transform: scale(1);
        box-shadow: 0 0 0 0 rgba(56, 189, 248, 0.7);
    }
    70% {
        transform: scale(1.05);
        box-shadow: 0 0 0 15px rgba(56, 189, 248, 0);
    }
    100% {
        transform: scale(1);
        box-shadow: 0 0 0 0 rgba(56, 189, 248, 0);
    }
}

/* Applying animation with shorthand */
.live-status-indicator {
    /* name | duration | timing-function | iteration-count */
    animation: pulseGlow 2s ease-out infinite;
    will-change: transform;
}
