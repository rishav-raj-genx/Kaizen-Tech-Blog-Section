Why This Matters

Every developer has experienced writing a CSS rule, refreshing the browser, and seeing nothing change—only to end up tacking on !important to force the style to apply. This habit triggers a specificity arms race that makes the codebase brittle and difficult to maintain.

Understanding selector priority and combinators allows you to target elements precisely without adding redundant classes or breaking the cascade.

Concept

CSS determines which style rule takes precedence through an algorithm called Specificity, calculated using a 4-part score (a, b, c, d):

  • Inline Styles (1, 0, 0, 0): Directly applied via the style="" attribute.
  • IDs (0, 1, 0, 0): E.g., #nav-header. High weight; best avoided for styling purposes.
  • Classes, Attributes & Pseudo-classes (0, 0, 1, 0): E.g., .btn, [type="checkbox"], :hover.
  • Elements & Pseudo-elements (0, 0, 0, 1): E.g., div, p, ::before.

Visual Diagram

SPECIFICITY COMPARISON MATRIX:
Selector                                | (Inline, ID, Class, Element) | Calculated Score
----------------------------------------+------------------------------+-----------------
style="color: red;"                     |          1,  0,     0,       0 | Highest priority
#header-title                           |          0,  1,     0,       0 | 100 points
header .nav-list li.active a            |          0,  0,     2,       3 |  23 points
.btn:hover                              |          0,  0,     2,       0 |  20 points
button                                  |          0,  0,     0,       1 |   1 point

* Note: 10 classes (0,0,10,0) will NEVER overpower 1 ID (0,1,0,0)!

Syntax

/* Combinators */
article p { /* Descendant: any p inside article */ }
article > p { /* Child: direct child p only */ }
h2 + p { /* Adjacent sibling: first p immediately following h2 */ }
h2 ~ p { /* General sibling: any p following h2 under same parent */ }

/* Modern Pseudo-classes */
button:not(.disabled) {
    cursor: pointer;
}

ul > li:is(:hover, :focus-within) {
    color: #38bdf8;
}

/* Pseudo-elements */
.quote::before {
    content: "“";
    font-size: 2rem;
}
