What are CRUD Operations

CRUD stands for Create, Read, Update, and Delete. These are the four basic operations used to manage data in MongoDB.

Whenever you build an application like a student management system, shopping website, or social media platform, you use CRUD operations to interact with the database.

Think of CRUD like managing a notebook:

  • Create → Write a new page.
  • Read → Read an existing page.
  • Update → Edit information on a page.
  • Delete → Remove a page.

For example, in a student database:

  • Add a new student → Create
  • View student details → Read
  • Change a student's course → Update
  • Remove a student record → Delete

Figure: CRUD is the foundation of any database operation.

Why it matters

CRUD operations are important because they are the foundation of every database application.

Some reasons why CRUD matters are:

  • It allows applications to store and manage data.
  • It helps users add, view, edit, and remove information.
  • Every web and mobile application uses CRUD operations.
  • MongoDB provides simple commands for performing CRUD.
  • CRUD makes database management fast and efficient.

Without CRUD operations, applications cannot interact with their databases.

Syntax

Create

db.students.insertOne({
    name:"Rituraj",
    age:19,
    course:"B.Tech AI"
});

Read

db.students.find();

Update

db.students.updateOne(
    { name:"Rituraj" },
    {
        $set: {
            age:20
        }
    }
);

Delete

db.students.deleteOne({
    name:"Rituraj"
});

Examples

Example 1: Create a Document

db.students.insertOne({
    name:"Riya",
    age:20,
    city:"Delhi"
});

This command adds a new student document to the students collection.

Example 2: Read Documents

Retrieve all students:

db.students.find();

Retrieve one specific student:

db.students.findOne({
    name:"Riya"
});

Example 3: Update a Document

db.students.updateOne(
    {
        name:"Riya"
    },
    {
        $set: {
            city:"Mumbai"
        }
    }
);

This updates Riya's city from Delhi to Mumbai.

Example 4: Delete a Document

db.students.deleteOne({
    name:"Riya"
});

This removes Riya's document from the collection.

Common Mistakes

Mistake 1: Forgetting a Filter in Update

Wrong

db.students.updateMany(
    {},
    {
        $set: {
            course:"AI"
        }
    }
);

This updates every document in the collection.

Correct

Always provide a filter unless you intentionally want to update all documents.

Mistake 2: Using deleteMany() Instead of deleteOne()

Wrong

db.students.deleteMany({
    name:"Riya"
});

This deletes every matching document.

Correct

Use deleteOne() if only one document should be removed.

Mistake 3: Forgetting the $set Operator

Wrong

db.students.updateOne(
    {
        name:"Riya"
    },
    {
        age:21
    }
);

This replaces the entire document instead of updating one field.

Correct

db.students.updateOne(
    {
        name:"Riya"
    },
    {
        $set: {
            age:21
        }
    }
);

Interview Questions

1. What does CRUD stand for?

Answer: CRUD stands for Create, Read, Update, and Delete. They represent the four fundamental persistent storage operations in software development and database systems.

2. Which command is used to insert a document in MongoDB?

Answer: In MongoDB, you use db.collection.insertOne() to insert a single document, or db.collection.insertMany() to insert an array of multiple documents into a collection.

3. What is the difference between find() and findOne()?

Answer:
• find() returns a cursor pointing to all documents that match the query criteria (or an empty cursor if none match).
• findOne() returns the first single document that satisfies the query criteria as a plain object (or null if no document matches).

4. What is the purpose of the $set operator in MongoDB?

Answer: The $set operator is an update field operator that replaces the value of a specified field with a new value without affecting or overwriting other fields in the document. Without $set, an update object will replace the entire document content.

5. What is the difference between deleteOne() and deleteMany()?

Answer:
• deleteOne() removes at most one single document matching the selection criteria, even if multiple documents match.
• deleteMany() removes all documents that match the specified query filter from the collection.
