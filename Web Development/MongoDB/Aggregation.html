What is Aggregation

Aggregation is a feature in MongoDB that allows you to process multiple documents and produce meaningful results.

Instead of simply retrieving data, Aggregation can filter, group, sort, calculate, and transform data.

Think of Aggregation like preparing a school report.

Imagine a teacher has marks of 500 students.

Instead of checking every student's marks one by one, the teacher wants to know:

  • Average marks
  • Highest marks
  • Number of students in each class
  • Total students who passed

Aggregation performs these calculations automatically.

Figure: Aggregation pipeline processes data through sequential stages ($match, $group, $sort, $project).

For example, suppose you have the following student records:

[
    { "name":"Riya", "course":"B.Tech AI", "marks":90 },
    { "name":"Anan", "course":"B.Tech AI", "marks":85 },
    { "name":"Rohan", "course":"BCA", "marks":78 }
]

Using Aggregation, MongoDB can calculate the average marks of students in each course.

Why it matters

Aggregation is important because it helps analyze large amounts of data efficiently.

Some reasons why Aggregation matters are:

  • It summarizes data quickly.
  • It performs calculations like average, sum, minimum, and maximum.
  • It groups similar documents together.
  • It filters data before processing.
  • It powers reports, dashboards, and analytics.

Without Aggregation, developers would need to process large datasets manually.

Syntax

Basic Aggregation Pipeline

db.students.aggregate([
    {
        $match:{
            course:"B.Tech AI"
        }
    },
    {
        $group:{
            _id:"$course",
            averageMarks:{
                $avg:"$marks"
            }
        }
    }
]);

Examples

Example 1: Find Average Marks

db.students.aggregate([
    {
        $group:{
            _id:null,
            averageMarks:{
                $avg:"$marks"
            }
        }
    }
]);

This calculates the average marks of all students.

Example 2: Count Students

db.students.aggregate([
    {
        $group:{
            _id:"$course",
            totalStudents:{
                $sum:1
            }
        }
    }
]);

This counts how many students belong to each course.

Example 3: Highest Marks

db.students.aggregate([
    {
        $group:{
            _id:null,
            highestMarks:{
                $max:"$marks"
            }
        }
    }
]);

This finds the highest marks among all students.

Example 4: Filter Then Group

db.students.aggregate([
    {
        $match:{
            course:"B.Tech AI"
        }
    },
    {
        $group:{
            _id:"$course",
            averageMarks:{
                $avg:"$marks"
            }
        }
    }
]);

This first filters B.Tech AI students and then calculates their average marks.

Common Mistakes

Mistake 1: Forgetting the $ Before Field Names

Wrong

$avg:"marks"

Correct

$avg:"$marks"

Always use $ before field names.

Mistake 2: Confusing find() with aggregate()

find() retrieves documents.

aggregate() processes and analyzes documents.

Use aggregate() when calculations or grouping are required.

Mistake 3: Incorrect Pipeline Order

Putting $group before $match may process unnecessary documents.

Correct

Filter first using $match, then group using $group.
