Concept

HTML tables organize structured, multi-dimensional information into rows and columns, establishing relational links between header categories and corresponding data points.

HTML 
<table>
  <caption>Server Status</caption>
  <tr>
    <th>Cluster</th>
    <th>Health</th>
  </tr>
  <tr>
    <td>US-East</td>
    <td>Operational</td>
  </tr>
</table>

Why This Matters

Tables should never be used to build web page layouts—that role belongs to CSS Grid and Flexbox. However, when displaying financial balance sheets, comparison matrices, or timetables, semantic tables communicate relationships between headers and values to screen readers.

Table Elements

  • <table>: Root container wrapper.
  • <caption>: Title describing the table's purpose.
  • <thead>, <tbody>, <tfoot>: Define structural sections for headers, data, and summary rows.
  • <th> & <td>: Header cells and standard data cells.
  • scope attribute: Specifies whether a header applies to a col or a row.

Syntax

Standard structured table implementation with explicit scope definitions:

HTML 
<table>
  <caption>Active System Users</caption>
  <thead>
    <tr>
      <th scope="col">ID</th>
      <th scope="col">Name</th>
      <th scope="col">Role</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">#01</th>
      <td>Jane Doe</td>
      <td>Admin</td>
    </tr>
  </tbody>
</table>

Rowspan & Colspan

Cells can merge across dimensions using colspan (horizontal spanning) and rowspan (vertical spanning):

HTML 
<tr>
  <!-- Spans across 2 columns -->
  <th colspan="2">Consolidated Metric</th>
</tr>
<tr>
  <!-- Spans vertically across 2 rows -->
  <td rowspan="2">Group A</td>
  <td>Score 1</td>
</tr>

Common Mistakes

  • Using <table> elements to create general UI layouts like navigation headers or multi-column grids.
  • Omitting the scope="col|row" attribute on <th> elements, leaving screen readers unable to correlate header contexts with data cells.
  • Miscalculating rowspan or colspan indices, causing table borders and cell alignments to break across rows.

Interview Questions

Q: Why is <caption> preferred over placing a heading tag above the table?

The <caption> tag is programmatically bound to the table by assistive technologies, ensuring screen reader users hear the table title when navigating to the element.

Quick Revision

Use tables only for tabular data. Structure them with <thead>, <tbody>, and <tfoot>, always include a <caption>, and declare scope="col" or scope="row" on every header cell.
