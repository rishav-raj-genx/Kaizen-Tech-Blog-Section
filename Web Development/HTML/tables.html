HTML Tables & Tabular Data

Why This Matters

During the early days of web design, tables were used to lay out entire web pages. Today, that technique is completely obsolete and strongly discouraged because it breaks responsive design and ruins screen-reader navigation. CSS Grid and Flexbox handle layouts; HTML tables exist strictly for tabular data.

When presenting data like stock market feeds, analytics dashboards, pricing tiers, or comparison matrices, a semantic table is the only element that communicates column-to-row relationships clearly to assistive tools.

Concept

A well-structured table requires distinct functional blocks:

  • <caption>: The heading or summary of the table for context.
  • <thead>, <tbody>, <tfoot>: Segment table sections logically, enabling browsers to repeat headers on printed pages.
  • <tr>, <th>, <td>: Table rows, header cells, and data cells respectively.
  • scope Attribute: Set on <th> (e.g., scope="col" or scope="row") to explicitly identify which data a header describes.

Syntax

<table>
    <caption>Quarterly Revenue Comparison (in Millions USD)</caption>
    <thead>
        <tr>
            <th scope="col">Quarter</th>
            <th scope="col">Projected</th>
            <th scope="col">Actual</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">Q1</th>
            <td>$12.5M</td>
            <td>$14.2M</td>
        </tr>
        <tr>
            <th scope="row">Q2</th>
            <td>$15.0M</td>
            <td>$16.8M</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <th scope="row">Total</th>
            <td>$27.5M</td>
            <td>$31.0M</td>
        </tr>
    </tfoot>
</table>
