Why This Matters

Imagine reading a newspaper where every headline, paragraph, quote, and caption was printed in the exact same font size and style. It would be nearly impossible to scan. That is what a website looks like to search engines and screen readers when it is composed entirely of unsemantic <div> and <span> tags (often called "div soup").

Semantic tags describe their meaning to both the browser and developer. A visually impaired user relying on assistive technology uses these landmarks to jump straight to the primary content instead of listening to repetitive navigation bars on every single page load.

Concept

HTML5 introduced structural semantic tags to standardize page architecture:

  • <header>: Introductory content, navigational links, or brand logos.
  • <nav>: Major navigational blocks intended for page-to-page links.
  • <main>: The central, dominant content unique to the document (only one per page).
  • <section>: A thematic grouping of content, typically with a heading.
  • <article>: Self-contained, syndicatable content (e.g., blog posts, product reviews).
  • <aside>: Content tangentially related to the main content, like sidebars.
  • <footer>: Authorship, copyright, legal links, or sitemap content.

Syntax

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Page Title</title>
</head>
<body>
    <header>
        <h1>Engineering Portal</h1>
        <nav>
            <ul>
                <li><a href="#home">Home</a></li>
                <li><a href="#articles">Articles</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <h2>Modern Web Standards</h2>
            <section>
                <h3>Accessibility Focus</h3>
                <p>Accessible applications start with proper markup structure.</p>
            </section>
        </article>
        <aside>
            <h3>Quick Links</h3>
            <p>Documentation notes and reference guides.</p>
        </aside>
    </main>

    <footer>
        <p>&copy; 2026 Kaizen Tech Blog. All rights reserved.</p>
    </footer>
</body>
</html>
