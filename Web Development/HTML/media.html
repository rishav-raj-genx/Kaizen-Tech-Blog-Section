Concept

HTML5 native media elements allow browsers to stream audio, video, and adaptive responsive pictures directly without requiring external plugins or proprietary runtimes.

HTML 
<video controls width="640">
  <source src="film.webm" type="video/webm">
  <source src="film.mp4" type="video/mp4">
  Your browser does not support HTML video.
</video>

Why This Matters

Media files account for most of the bytes transferred across the web. Sending heavy desktop images to mobile devices drains bandwidth and slows page loads. Using modern elements like <picture> allows browsers to request the right format (AVIF, WebP) and size for the user's screen.

Core Media Elements

  • <video>: Renders video with support for playback controls, loop states, and posters.
  • <audio>: Embeds sound clips and audio streams natively.
  • <picture>: Wrapper that serves different images based on media queries or format support.
  • <track>: Supplies timed text tracks (subtitles, captions, chapter marks) for accessible media.

Syntax

Using the <picture> element to serve modern image formats with a fallback:

HTML 
<picture>
  <source srcset="banner.avif" type="image/avif">
  <source srcset="banner.webp" type="image/webp">
  <img src="banner.jpg" alt="Conference keynote" loading="lazy" width="800" height="450">
</picture>

Subtitles & Captions

Embed WebVTT subtitle files directly within a video container:

HTML 
<video controls poster="preview.jpg">
  <source src="tutorial.mp4" type="video/mp4">
  <track src="captions-en.vtt" kind="captions" srclang="en" label="English" default>
</video>

Common Mistakes

  • Omitting explicit width and height attributes on <img> and <video> tags, which causes layout shifts (CLS) while assets load.
  • Forgetting to add descriptive alt text on the fallback <img> inside a <picture> tag.
  • Enabling autoplay on video elements without also setting muted, which causes modern browsers to block playback.

Interview Questions

Q: How does the <picture> element differ from the srcset attribute on an <img> element?

srcset lets the browser decide which image resolution fits best based on screen density, whereas <picture> allows the developer to enforce specific image crops or file formats (art direction).

Quick Revision

Wrap videos with multiple <source> formats (WebM, MP4) and subtitles. Use <picture> for responsive images, and include loading="lazy" along with dimensions on <img> tags to keep pages fast.

Practice Problems

  2. Create a custom podcast player using the native <audio> tag with chapter markers.
