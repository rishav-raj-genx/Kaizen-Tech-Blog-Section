Why This Matters

Media makes up over 60% of the byte weight of modern websites. Shipping desktop-sized 4K images to a smartphone on a flaky 3G connection causes poor performance, lowers Core Web Vitals, and hurts search rankings.

HTML5 native media elements eliminated the need for heavy, insecure third-party plugins (like Flash) and introduced native controls, hardware acceleration, responsive asset negotiation via <picture>, and accessibility tracks via <track>.

Concept

HTML offers several purposeful media elements:

  • <video>: Embeds video streams natively with configurable controls, autoplaying, looping, and preloading properties.
  • <audio>: Streamlines sound files and podcasts using the same multi-source fallback pattern as video.
  • <source>: Allows you to supply multiple video/audio formats (e.g., AV1, WebM, MP4) so the browser downloads the first format it supports.
  • <picture> & srcset: Lets you serve next-gen image formats (AVIF, WebP) with a fallback to JPEG/PNG, or serve different image crops based on viewport width.

Syntax

<!-- Responsive Image Selection -->
<picture>
    <source srcset="hero-large.avif" type="image/avif" media="(min-width: 1024px)">
    <source srcset="hero-large.webp" type="image/webp" media="(min-width: 1024px)">
    <source srcset="hero-small.webp" type="image/webp">
    <img src="hero-fallback.jpg" alt="Developer working on modern web components" loading="lazy" width="800" height="450">
</picture>

<!-- Native Accessible Video -->
<video controls preload="metadata" poster="poster.jpg" width="640" height="360">
    <source src="demo.webm" type="video/webm">
    <source src="demo.mp4" type="video/mp4">
    <track src="subtitles-en.vtt" kind="subtitles" srclang="en" label="English" default>
    Your browser does not support native video playback.
</video>
