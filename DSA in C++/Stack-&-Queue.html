A **Stack** is a linear data structure that follows the **LIFO (Last In, First Out)** principle. The last element inserted into the stack is the first one to be removed. Only one end of the stack, called the **Top**, is used for insertion and deletion. --- # Why Stacks Matter Stacks are used whenever you need to remember the most recent item first. Examples include: * Undo/Redo in editors * Browser back button * Function call management * Expression evaluation * Parentheses matching * DFS in Graphs * Backtracking algorithms --- # Think Like This... Imagine a stack of dinner plates. You always place a new plate on the top. When removing a plate, you also remove it from the top. You cannot remove a plate from the middle. A Stack behaves in exactly the same way. --- # LIFO Principle LIFO stands for **Last In, First Out**. Example: ```text Push 10 Push 20 Push 30 Stack Top ↓ 30 20 10 Pop 30 removed first ``` --- # Visual Diagram ```text TOP ↓ +---------+ | 40 | +---------+ | 30 | +---------+ | 20 | +---------+ | 10 | +---------+ ``` Push adds a new element to the top. Pop removes the top element. --- # Basic Operations ## Push Adds an element to the top. Example Before ```text 20 10 ``` After Push(30) ```text 30 20 10 ``` Complexity O(1) --- ## Pop Removes the top element. Example Before ```text 30 20 10 ``` After Pop() ```text 20 10 ``` Complexity O(1) --- ## Top / Peek Returns the top element without removing it. Complexity O(1) --- ## isEmpty() Checks whether the stack contains any elements. Complexity O(1) --- ## Size() Returns the total number of elements. Complexity O(1) --- # Stack Implementation using Array ```cpp #include using namespace std; class Stack { int arr[100]; int topIndex; public: Stack() { topIndex = -1; } void push(int x) { arr[++topIndex] = x; } void pop() { if(topIndex >= 0) topIndex--; } int top() { return arr[topIndex]; } bool empty() { return topIndex == -1; } }; ``` Advantages * Fast * Cache friendly * Simple implementation Disadvantages * Fixed size --- # Stack Implementation using Linked List ```cpp class Node { public: int data; Node* next; Node(int x) { data=x; next=nullptr; } }; class Stack { Node* topNode; public: Stack() { topNode=nullptr; } void push(int x) { Node* temp=new Node(x); temp->next=topNode; topNode=temp; } void pop() { if(topNode==nullptr) return; Node* temp=topNode; topNode=topNode->next; delete temp; } }; ``` Advantages * Dynamic size * No overflow until memory is exhausted --- # Stack using STL ```cpp #include using namespace std; int main() { stack st; st.push(10); st.push(20); st.push(30); cout< using namespace std; class Queue { int arr[100]; int frontIndex; int rearIndex; public: Queue() { frontIndex = 0; rearIndex = -1; } void enqueue(int x) { arr[++rearIndex] = x; } void dequeue() { if(frontIndex <= rearIndex) frontIndex++; } int front() { return arr[frontIndex]; } bool empty() { return frontIndex > rearIndex; } }; ``` Advantages * Simple implementation * Fast access Disadvantages * Wasted memory after multiple dequeue operations * Fixed size --- # Queue Implementation using Linked List ```cpp class Node { public: int data; Node* next; Node(int x) { data = x; next = nullptr; } }; class Queue { Node* frontNode; Node* rearNode; public: Queue() { frontNode = rearNode = nullptr; } void enqueue(int x) { Node* temp = new Node(x); if(rearNode == nullptr) { frontNode = rearNode = temp; return; } rearNode->next = temp; rearNode = temp; } void dequeue() { if(frontNode == nullptr) return; Node* temp = frontNode; frontNode = frontNode->next; if(frontNode == nullptr) rearNode = nullptr; delete temp; } }; ``` Advantages * Dynamic size * Efficient memory usage * No fixed capacity --- # Circular Queue A Circular Queue connects the last position back to the first position. Instead of wasting unused array positions, it reuses them. Visual ```text FRONT ↓ +----+----+----+----+ |10 |20 |30 |40 | +----+----+----+----+ ↑ ↓ └─────────────────┘ ``` Applications * CPU Scheduling * Buffers * Streaming * Network Routers --- # Queue using STL ```cpp #include using namespace std; int main() { queue q; q.push(10); q.push(20); q.push(30); cout << q.front() << endl; cout << q.back() << endl; q.pop(); cout << q.size(); } ``` Common STL Functions | Function | Description | | -------- | ------------------ | | push() | Insert element | | pop() | Remove front | | front() | First element | | back() | Last element | | empty() | Check empty | | size() | Number of elements | --- # Time Complexity | Operation | Complexity | | --------- | ---------- | | Enqueue | O(1) | | Dequeue | O(1) | | Front | O(1) | | Rear | O(1) | | Size | O(1) | | Empty | O(1) | --- # Advantages * Maintains insertion order * Constant-time insertion * Constant-time deletion * Efficient scheduling * Easy implementation --- # Disadvantages * No random access * Array implementation has fixed capacity * Standard array queue wastes space without circular implementation --- # Real-World Applications * Printer Queue * CPU Scheduling * BFS Traversal * Call Center Systems * Ticket Reservation * Network Packet Scheduling * Chat Message Delivery * Video Streaming Buffers * Task Scheduling * Web Server Request Handling --- # Common Mistakes ## Mistake Calling dequeue() on an empty queue. Why? Queue Underflow occurs. Correct Way Always check empty() before dequeue(). --- ## Mistake Accessing front() on an empty queue. Always verify that the queue is not empty. --- ## Mistake Ignoring rear update after deleting the last element. Always reset both front and rear to nullptr when the queue becomes empty. --- ## Mistake Using a simple array queue where a circular queue is needed. Result Memory is wasted even though free positions exist. --- # Interview Questions 1. What is a Queue? 2. Explain FIFO. 3. Difference between Stack and Queue. 4. Implement Queue using Array. 5.
