Python Basics

Python is a high-level programming language known for its simplicity and readability. It is widely used in Data Science, Machine Learning, Web Development, and Automation.

Example

print("Hello World")

Variables

Variables are containers used to store data. 

name = "John"
age = 20
cgpa = 8.5

Loops

Loops allow us to repeat a block of code multiple times. 

for i in range(5):
    print(i)

Functions

Functions help us write reusable code. 

def add(a,b):
    return a+b

print(add(10,20))

OOP Basics

Object-Oriented Programming organizes code into classes and objects. 

class Student:

    def __init__(self,name):
        self.name=name

    def display(self):
        print(self.name)

s=Student("Aditya")
s.display()
