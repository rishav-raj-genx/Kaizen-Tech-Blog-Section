Introduction

Seaborn is a Python visualization library built on top of Matplotlib. It provides beautiful default styles and simplifies statistical plotting. 

import seaborn as sns
import matplotlib.pyplot as plt

Line Plot

import seaborn as sns
import matplotlib.pyplot as plt

x=[1,2,3,4]
y=[10,20,15,25]

sns.lineplot(x=x,y=y)

plt.show()

Heatmap

import seaborn as sns

import matplotlib.pyplot as plt

"A":[1,2,3],
"B":[4,5,6],
"C":[7,8,9]
}

sns.heatmap(df)
